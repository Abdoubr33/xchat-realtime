🚀 Set up XChat

This is a real-time chat template. To let different people chat from their own devices, connect it to a free Firebase project. You only need to do this once.

  1. Open https://console.firebase.google.com/ and create a project.
  2. Add a Web App (the </> icon) and copy its Firebase config values below.
  3. In Build → Authentication, enable Anonymous sign-in.
  4. Create a Realtime Database and Storage bucket. Apply the security rules included with this HTML download's setup instructions.
